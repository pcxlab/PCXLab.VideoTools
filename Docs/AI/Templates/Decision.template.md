# Architectural Decision

## Purpose

This template is used to record significant architectural decisions for the project.

Architectural decisions should explain **why** a decision was made rather than simply describing **what** was implemented.

These records provide long-term context for developers and AI assistants, reducing the need to rediscover historical reasoning.

# AI Context

This document should allow a future AI assistant to answer:

- Why was this decision made?
- What alternatives were considered?
- What trade-offs were accepted?
- What future work remains?

without re-analyzing the repository.

---

# Update Rules

Architectural decisions should remain permanent.

If a later decision supersedes this one, create a new decision record rather than rewriting history.
