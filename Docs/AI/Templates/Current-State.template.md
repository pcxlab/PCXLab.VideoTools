# Current Project State

## Purpose

This template is used to maintain `Docs/Current-State.md`.

It records the current state of the project at a specific point in time.

Unlike the Project Vision document, this document should always describe the project **as it exists today**.

It should provide enough information for developers and AI assistants to quickly understand the current implementation without analyzing the entire repository.
